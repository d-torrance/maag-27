{%- comment -%} MathJax 3, loaded only on pages that ask for it (front matter `math: true`). kramdown runs with `math_engine: null` (see _config.yml), so it detects math and emits it with delimiters intact, wrapped in `.kdmath`: inline: $...$ display:
$$...$$
We therefore tell MathJax to ignore the document by default and process only those `.kdmath` containers. Without this, MathJax would scan all prose for `$...$` and mangle ordinary dollar amounts ("expenses over $25 ... $50"). The version is pinned so the integrity hash stays valid -- a floating `mathjax@3` URL would break SRI on the next patch release. To upgrade: curl -sL https://cdn.jsdelivr.net/npm/mathjax@X.Y.Z/es5/tex-chtml.js \ | openssl dgst -sha384 -binary | openssl base64 -A {%- endcomment -%}
